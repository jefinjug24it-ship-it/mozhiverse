# 🌐 MozhiVerse

### Different Languages. Different Abilities. One Conversation.

## 📌 Abstract
MozhiVerse is a web-based communication application designed to reduce communication barriers caused by different languages and speech difficulties. It supports Tamil-to-English and English-to-Tamil text translation, voice input, speech output, editable translations, and conversation history.

## 🎯 Objectives
- Enable communication between Tamil and English speakers.
- Provide voice input and text-to-speech output.
- Support users with different communication needs.
- Allow users to correct translations and save conversation history.
- Provide a simple and responsive user interface.

## ✨ Features
- Tamil ↔ English translation
- Voice input using browser speech recognition
- Text-to-speech output
- Editable translated text
- Save corrections and conversation history
- Clear conversation history
- Simple web interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- MyMemory Translation API
- Web Speech API
- Browser Local Storage

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` using a browser, or use the VS Code Live Server extension.
4. Connect to the internet to use translation.
5. Allow microphone access when using voice input.

## ⚠️ Limitations
- Translation quality depends on the external translation service.
- Voice recognition support depends on the browser and device.
- Translation requires an internet connection.
- Conversation history is stored in the current browser.

## 🔮 Future Scope

- More Indian and international languages
